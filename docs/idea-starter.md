# 想法入口更新记录 · 2026-10-09

基于主分支 `3dfd27a`，新增面向普通用户的轻量流程：想法 → 小尝试 → 行动卡。原项目表单保留。只写一句想法即可整理；建议由浏览器规则生成，不调用模型。后续通过复制提示交给用户自己的 AI 助手继续。

- 行动可编辑、勾选，并记录尝试反馈；修改想法保留已有行动，提示输入版本变化。
- 转为项目创建独立草稿，只携带用户明确填写的目标、验收期望、条件和备注，技术与交付深度仍待选择。
- 旧备份默认按项目模式读取；想法备份保留输入、行动、勾选与反馈。
- 两条路径共用导航计数、草稿和备份操作，说明文字按需展开。
- 没有增加运行依赖、外部模型请求、账号或云端存储。

## 发布与现有限制

本版本用于独立仓库 `lizi-product-studio/dingxinglizi-ideas`。原仓库 `lzq-teach/dingxinglizi` 和原在线站点未替换；代码上传与网站发布分别处理。

新仓库默认在推送 `main` 时自动测试，不自动发布网站。需要上线时，先在仓库 Settings → Pages 启用 GitHub Actions，再手动运行发布工作流。发布后应核对首屏双入口、旧草稿、一个完整想法流程和静态文件加载。

当前页面仍为静态工具：不会动态追问、研究市场或自动制作成品；不会跨设备同步。要让用户在页面内连续对话并生成作品，需要另行确定服务端模型连接、用户隔离与用量限制。密钥和本机 Codex 登录不得放入 GitHub Pages 前端。
